# Problem Statement

## Background

The rapid growth of Internet of Things (IoT) devices has introduced major security challenges. Many low-cost embedded systems have limited hardware protection, making them vulnerable to unauthorized memory access, malicious firmware modification, and control-flow attacks.

Traditional software-based security mechanisms consume processing resources and may fail when the underlying hardware itself is compromised.

## Problem

Design a lightweight hardware-assisted secure RISC-V processor that improves the security of resource-constrained embedded systems while maintaining low hardware complexity.

## Objectives

- Design a modular RISC-V processor architecture.
- Add hardware-based memory protection.
- Implement instruction verification.
- Detect unauthorized memory access.
- Create a scalable RTL design suitable for FPGA implementation.

## Expected Outcome

A processor architecture that demonstrates how lightweight hardware security can improve the reliability of embedded IoT devices.
