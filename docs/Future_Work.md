# Future Work

## Planned Enhancements

The current SecureRISC architecture serves as the initial version of the project.

Future improvements include:

- 5-stage pipelined RISC-V processor
- Cache memory support
- Branch prediction
- Secure Boot implementation
- Cryptographic Accelerator (AES)
- Hardware Trojan Detection
- Secure Debug Interface
- FPGA implementation using Vivado
- ASIC implementation using OpenROAD
- Performance benchmarking

## Long-Term Goal

Develop SecureRISC into an open-source secure processor platform for embedded and IoT applications.
