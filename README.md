## 🔐 Featured Project

### SecureRISC

**Hardware-Assisted Secure RISC-V-Style Processor**

A 32-bit processor implemented in Verilog RTL with hardware-assisted
security mechanisms.

**Key work:**

- Instruction verification
- Memory Protection Unit (MPU)
- Illegal instruction detection
- Unauthorized memory access blocking
- CPU integration
- Security attack simulation
- Icarus Verilog verification
- GTKWave waveform analysis
- GitHub Actions CI

🔗 **Project:** https://github.com/mayursn-007/SecureRISC
